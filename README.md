MyAstra:
It is an experimental AI coding assistant built using the Astra API to explore how AI models can be integrated into a simple web application.

I built it with HTML, CSS, and JavaScript, using a Netlify serverless function to connect the frontend to the Experiential Labs API with the gpt-6-astra-pro model.

What it includes:
A minimal, dark-themed chat interface
Conversation context during a browser session
Formatted code snippets and responses
Server-side API requests to keep the API key out of the frontend
